# Multi-Repository Contract

An application is an explicit graph of repositories, contracts, data stores, deployment units, and external systems. Directory proximity and naming similarity are candidate hints only.

Every cross-repository edge requires one of:

- direct source evidence from producer and consumer;
- a shared machine-readable contract;
- deployment or dependency evidence;
- a recorded human confirmation.

Review and QnA operate against an application snapshot that resolves every participating repository to an immutable revision or worktree digest.
