# Phase 1 Assurance

Phase 1 is complete when:

- every role has explicit allow and deny authority;
- every canonical artifact has exactly one writer;
- every workflow state maps to one owner and declared outputs;
- source write is denied globally;
- only the memory curator writes canonical memory;
- terminal workers cannot delegate;
- facts without evidence fail schema validation;
- major findings without critic challenge fail schema validation;
- stale evidence use is prohibited by policy;
- economy execution is sequential, structured, and flagship-independent;
- all positive and negative contract tests pass.
