# Output Quality Contract

Consistency is produced by stable IDs, canonical templates, JSON Schemas, deterministic ordering, coverage ledgers, explicit epistemic labels, fresh independent critique, and semantic verification.

A comprehensive documentation claim is valid only for a declared scope and must report discovered, documented, partial, excluded, and unknown items. A full codebase review similarly requires a coverage ledger.

CodeRabbit-style layout and Mintlify-ready rendering are future exporters. Their output must remain projections of canonical Markdown, structured findings, and traceability records.
